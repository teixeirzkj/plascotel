# Ideias de melhoria — Plascotel

Lista viva de sugestões pra deixar o site e o admin cada vez mais parecidos
com uma loja de verdade. Marcadas como feitas conforme forem implementadas.

## Já feito

- [x] Busca por nome do cliente ou número do pedido (admin)
- [x] Exportar pedidos do mês em CSV
- [x] Notificação sonora/visual de pedido novo (admin, tempo real)
- [x] Filtro de "carrinho abandonado" no admin (pedidos InfinitePay expirados)
- [x] Zoom ao passar o mouse na foto do produto
- [x] Avaliações/estrelas simples (definidas pelo admin)
- [x] "Você também pode gostar" (produtos relacionados)
- [x] Aviso de "Últimas X unidades" (estoque baixo)
- [x] Código de rastreio dos Correios (admin registra, cliente vê no status do pedido)
- [x] Barra de busca leva pra uma página de resultados filtrada por nome
- [x] Skeleton/loading state (produto, listagem, categoria)
- [x] Breadcrumb (Início > Categoria > Produto)
- [x] Barra fixa de "Adicionar ao carrinho" no celular

## Pendente

### Confiança / credibilidade
- [ ] CNPJ e endereço da empresa no rodapé (exigência legal de e-commerce no Brasil)
- [ ] Selos de pagamento seguro perto do botão de finalizar compra
- [ ] Depoimentos/avaliações reais de clientes em destaque na home
- [ ] Parcelamento visível no produto ("ou 3x de R$X sem juros")

### Conversão
- [ ] Frete calculado direto na página do produto (não só no carrinho)
- [ ] Cupom de desconto no checkout
- [ ] Favoritos / lista de desejos (❤ salvar produto)
- [ ] Lembrete automático de carrinho abandonado (depende de configurar a API de WhatsApp Business — mesma pendência da notificação de pagamento)

### Descoberta (SEO / anúncios)
- [ ] Meta tags por produto (título, descrição, imagem) — pra aparecer bem ao compartilhar no WhatsApp/Instagram e no Google
- [ ] Google Analytics / Meta Pixel
- [ ] Sitemap.xml

### Admin
- [ ] Destaque de estoque baixo direto na lista de produtos (hoje só aparece no dashboard)
- [ ] Relatório de produtos mais vendidos
